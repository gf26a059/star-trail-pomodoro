# Star Trail Pomodoro

An ASCII time-lapse of the night sky from a fixed camera, built as a Pomodoro timer.

- One focus session is one night (19:00 to 05:00). The shutter stays open while you focus, so star trails grow around the pole as you work.
- One break is one day (06:00 to 18:00). The sun crosses the sky and the trails fade.
- Every cell is a single character. One hue, only lightness changes.

Keys: `Space` start/pause, `R` reset, `N` skip.

Single file, no dependencies: open `index.html` or visit the GitHub Pages site.
